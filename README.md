# PolyPainter

An interactive viewer for the five Platonic solids, built with [three.js](https://threejs.org) and [Vite](https://vite.dev).

Pick a solid from the toolbar, drag to rotate it, and scroll (or pinch) to zoom.

## Development

```sh
npm install
npm run dev      # start the dev server
npm run build    # production build in dist/
```
